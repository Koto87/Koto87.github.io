# Henry Dakota Gentry
### Middle-School Science Educator · Educational Technology Builder

I teach **7th-grade science and honors science** and build practical technology around the real work of teaching. I care about thoughtful instruction, consistent classroom routines, meaningful assessment, and tools that help educators spend less time on repetitive tasks and more time supporting students.

## What I focus on

- **Science education:** inquiry, evidence, and helping students explain their thinking.
- **Instructional design:** clear goals, predictable lesson structures, and purposeful independent work.
- **Educational technology:** practical tools shaped by real classroom needs.
- **Responsible automation:** transparent workflows, teacher oversight, and reliability before complexity.

## Current project

### Gentry OS — Teacher Operations Center
An educator-centered workspace in active development. The project explores clearer classroom workflows, repeatable processes, and carefully controlled automation for educational work. It is being developed incrementally, with reliability, teacher oversight, and transparent actions as priorities.

The application source repository is currently private, so this portfolio describes the project without implying that its implementation is publicly available or production-complete.

## Professional principle

> Technology should serve learning—not the other way around.
